Open a dataviz file Any standard as an interactive dependency graph

dataviz shows a standard as an interactive graph you can filter, explore and assess against. It reads dataviz files: a simple description of the standard's items, links and filters, in JSON, YAML, Excel or CSV. Nothing is uploaded and there is no account: files are read in your browser and stay there.

Open a dataviz file

Only have the standard as a PDF or a Word document? Turn it into a dataviz file first, below.

Make a dataviz file

  1. With an AI assistant. Copy our prompt, paste it into the assistant you use with the standard attached, save its answer as a .yaml file and drop it above (or open it in the builder to check and fix it). read it
  2. By hand, from a template. Fill it in with your usual tools: Excel YAML JSON CSV items · CSV links
  3. In the builder, item by item with a live preview, then export or share it. Open the builder

Every field is explained in the format reference; this example uses them all.

Open from a web address

A dataviz file published on the web (GitHub raw files, gists, your own site). The server must allow cross-origin reads. The address goes after the # of the page link, so the link can be shared, and it never reaches our server.
